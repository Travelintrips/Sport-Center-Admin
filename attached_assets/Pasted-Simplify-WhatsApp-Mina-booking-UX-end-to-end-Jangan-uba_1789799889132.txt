Simplify WhatsApp Mina booking UX end-to-end. Jangan ubah Web Mina, Fonnte transport, admin WA, accounting, payment calculation, availability rules, tax, atau canonical booking lifecycle. Tujuannya membuat booking WhatsApp semudah berbicara dengan front office. Mina harus mengekstrak sekaligus semua informasi yang sudah disebut customer dari natural language (facility, date, start time, duration, customer name bila tersedia) dan hanya menanyakan field REQUIRED yang masih kurang. Jangan lagi memaksa sequential form ask_facility→date→time→duration→name→notes→confirm. Notes optional jangan ditanyakan kecuali customer menyebutkannya. Gunakan nomor WA/customer profile/existing customer data untuk nama jika sudah tersedia; jangan menanyakan ulang data yang sudah diketahui. Setelah facility+date+time+duration lengkap, langsung jalankan canonical availability + price calculation. Jika tersedia, tampilkan ringkasan singkat facility/date/time/duration/total dan hanya minta data wajib yang belum ada. Jika seluruh required data sudah tersedia dan intent customer jelas meminta booking, buat booking melalui existing canonical booking service dengan source whatsapp_ai; jangan membuat duplicate booking path. Untuk kalimat lengkap seperti booking badminton besok jam 7 malam 2 jam atas nama Alif, target maksimal: parse → availability/price → satu konfirmasi singkat → create booking. Untuk customer existing yang identitasnya sudah valid, hindari pertanyaan nama. Support koreksi natural seperti jamnya ganti jam 8, jadi 1 jam saja, besoknya lusa, tanpa restart session. Jika slot tidak tersedia, langsung tawarkan maksimal 3 slot terdekat dari canonical availability. Setelah booking berhasil, kirim booking number + jadwal + total + next payment action/link bila applicable. Jangan meminta login website untuk WhatsApp booking. Preserve idempotency/dedupe dan final availability check sebelum insert. Tambahkan regression tests untuk one-message booking, partial booking, existing customer, correction, unavailable slot alternatives, duplicate message, dan concurrent slot conflict. Typecheck + build + targeted tests. Jangan kirim WhatsApp nyata selama verifikasi.
