# 4. HARDEN EXISTING QRIS MATCHER

Audit:

`bankMatcher.ts`

dan jalur matcher QRIS existing.

Untuk QRIS, automatic candidate matching wajib menggunakan hard boundaries:

`company_id`
+
`bank_account_id`
+
`payment_provider`
+
`expected_settlement_date`

Configured MDR/tolerance digunakan sebagai validation layer.

Jangan hanya menggunakan nominal + tanggal generik.

## Provider

Mandiri Direct tidak boleh match Paylabs.

Paylabs tidak boleh match Mandiri Direct.

Unknown provider:
`REVIEW`

## Bank account

NULL tidak boleh menjadi wildcard.

Different account:
tidak boleh cross-match.

## Settlement date

Gunakan business-day-aware expected settlement date/rule snapshot.

Jangan menggunakan generic calendar ±1 day jika QRIS provider rule tersedia.

## MDR

Observed:

`gross - bank credit`

Bandingkan dengan effective-dated expected MDR + tolerance.

Rate saja tidak boleh membuat MATCHED jika provider/account/date tidak valid.
