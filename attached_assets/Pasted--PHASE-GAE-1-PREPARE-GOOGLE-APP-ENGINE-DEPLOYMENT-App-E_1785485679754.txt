## Phase 1 — Audit

Audit seluruh repository dan tentukan:

- production entry point
- Express entry point
- folder deployment yang benar
- package.json yang digunakan production
- build pipeline
- start command
- output directory
- apakah project merupakan monorepo
- dependency yang digunakan App Engine

## Phase 2 — App Engine Compatibility

Pastikan:

- aplikasi berjalan menggunakan Node.js
- server listen pada:

process.env.PORT

dan

0.0.0.0

- tidak ada hardcoded port
- tidak ada hardcoded localhost
- graceful shutdown tetap berjalan

## Phase 3 — Deployment Files

Buat atau perbaiki bila diperlukan:

- app.yaml
- cloudbuild.yaml
- .gcloudignore

Gunakan:

Service:
default

Runtime:
Node.js (sesuai versi project)

Automatic scaling yang sesuai.

## Phase 4 — Build

Pastikan build production menjalankan seluruh pipeline termasuk:

- pnpm install
- build seluruh workspace yang diperlukan
- Vite build
- prerender seluruh halaman publik

Pastikan hasil build menghasilkan HTML unik untuk:

/
 /facilities
 /promos
 /membership
 /contact
 /privacy
 /terms

## Phase 5 — SEO Verification

Verifikasi raw HTML production build memiliki:

- unique title
- unique meta description
- canonical
- og:url
- og:image
- twitter:image

Pastikan bukan metadata hasil hydration.

- GitHub
