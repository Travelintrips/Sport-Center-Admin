Date: 2026-11-03 (Asia/Jakarta)
Scope: standalone offline browser harness, synthetic PIN 500 only.
No photo upload to any service, no X904 device command, and no real member photograph.

## Automated Chromium browser regression on VPS

Source under test: commit `7d7b13f492824dc8586210ca3d4038f074253b6e`, `scripts/x904-offline-face-intake/phone-preview.html`. The exact HTML fetched successfully from the dedicated preview branch (HTTP 200, 5,616 bytes) and was tested from a local `file://` copy inside Chromium so third-party hosting interstitial behavior could not be mistaken for app requests.

### Successful synthetic JPEG case
- Input: synthetic JPEG generated by a browser canvas; 194,953 bytes.
- Validation status: `STAGED_OFFLINE_ONLY`.
- Output: 49,147 bytes, 560 × 560 pixels.
- Downloaded name: `verify_biophoto_9_500.jpg`.
- Actual downloaded bytes: 49,147 bytes, header FF D8 FF, terminal FF D9.
- Requests after document load during validation and download: **zero**.
- Change PIN to 501: download disabled; change it back to 500: remains disabled until fresh validation.

### Negative cases
- PNG extension: `DITOLAK: EXTENSION_INVALID`; download disabled.
- Wrong PIN 501: `DITOLAK: TEST_PIN_ONLY`; download disabled.
- Undersized fake JPEG: `DITOLAK: INPUT_SIZE_INVALID`; download disabled.
- Network requests after page load in all negative tests: zero.
