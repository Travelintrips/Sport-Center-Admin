---
name: Mina booking URL authority
description: The invariant for booking links generated by the Web Mina assistant.
---

Web Mina booking links are backend-authoritative: construct them from the shared `getBaseUrl()` helper, preserve `facilityId`, `date`, `startTime`, `duration`, and `source=web`, and replace any model-rewritten URL before returning the reply.

**Why:** The assistant model can rewrite or invent a URL after receiving a tool result; that can send customers to the wrong host or change the booking context.

**How to apply:** Keep URL construction and final reply canonicalization server-side. Do not read `process.env.APP_URL` directly from Mina tools or trust a URL emitted by the model.
